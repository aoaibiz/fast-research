# 24 問の比較記録（2026-11-02）

目的：公開情報の根拠取得を改善し、手元の資料の外部送信を防ぐ。外部検索の速さや正答率を推測で改善扱いしない。

固定24問（開発・営業・SNS各8問）を旧版/改造版で交互に1回ずつ測定。候補は2種類まで、各30分上限、課金0。公開Webの変動・キャッシュ・上流制限あり。合格条件は想定ドメインの上位5件出現が旧版以上であること、取得状態を明示すること。これは正答率ではない。

| 測定 | 旧版 | 改造版 |
|---|---:|---:|
| 第1候補：想定ドメイン上位5件 | 24/24 | 23/24 |
| 第1候補：応答中央値 | 3.0773秒 | 2.0714秒 |
| 第2候補：想定ドメイン上位5件 | 24/24 | 24/24 |
| 第2候補：応答中央値 | 2.26635秒 | 2.6119秒 |
| 第2候補：応答95%点（実装の近似順位） | 5.1737秒 | 4.4183秒 |
| 第2候補：本文文字数合計 | 580,552 | 465,980 |
| 第2候補：取得品質okが付いたページ | 指標未実装 | 90 |

第1候補は不採用。HubSpot公式の本文取得不足により「本文取得済み優先」の順位変更が公式ページを6番目へ下げた。本文取得品質と検索順位を分離し、優先ドメイン内は検索元の関連順を保持する第2候補で再比較した。第2候補はこの固定セットの非劣化条件を満たしたため採用した。一般的な品質向上や高速化の証明とはしない。本文量は減っており、回答の完全性を保証しない。

次に順位調整を行う時もこの固定セットと同じ合格条件で比較する。悪化したら `core.py` の順位処理を直前の版へ戻す。評価基準を候補に合わせて変更しない。

質問セット `workbench/evaluation/questions.json` と評価器 `workbench/evaluation/compare.py` を同梱しています(生の測定の記録は同梱していません)。課金額0は有料APIを使用していないことを意味し、電力・開発時間・モデル利用料を含む総費用ではない。
