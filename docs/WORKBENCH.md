# 画面の使い方・保存・戻し方

AI を使わずに自分で調べる時の、手元だけで動く画面です。AI から使うだけなら要りません。

## 起動と終了

```sh
python3 -m workbench.server --binary "$(pwd)/target/release/rustxng"
```

- ブラウザーで http://localhost:18890 を開きます。この PC から開くと、そのまま使える状態で開きます(最初の 1 人がこの PC の管理者になります)。
- 画面は 127.0.0.1 だけで待ち受けます。別の PC・スマホからは開けません。
- 終了は画面の「設定」の停止ボタン、またはターミナルで Ctrl+C。
- macOS では `RustXNG.app` からも起動できます(中の `launch` に書かれた Python のパスを、自分の PC の物に合わせてください)。

## できる事

| 画面 | 中身 |
|---|---|
| 調べる | 公開 Web・自分の資料・両方を検索し、出典 URL・取得時刻・本文の該当箇所・取得の品質を並べる |
| 社内資料 | 自分で登録したテキストを、外へ送らずに検索する |
| 保存した調査 | 実行した調査の再表示と Markdown での保存 |
| 設定 | 検索エンジンの再起動・バックアップと復元・停止・ソースの取得(AGPL) |
| AIとつなぐ | 自分の AI に入れる案内のコピー・この PC 用の接続設定の保存 |

- 公開 Web の検索は、検索語を検索サイトへ送ります。送る前に確認の欄を選びます。両方の検索では、資料用の語と公開用の語を別々に入力します。
- 根拠の真偽・最新性・完全な答えは自動では保証しません。金額の違いは「食い違いの候補」で、同じ条件の比較とは限りません。

## 保存の場所と上限

- 保存先は `local-data/workbench.sqlite`(このフォルダーの中・`--data` で変えられます)。利用者ごとに資料と調査を分けて保存します。パスワードは PBKDF2、セッションはハッシュで保存し、診断の記録には検索語・本文・認証の値を書きません。
- 上限: 資料は 1 人 500 件・合計 1.5MB、保存した調査は合計 10MB、復元するバックアップは 16MB まで。超えると理由を表示し、勝手には消しません。
- 同じ PC の管理者や、同じ OS アカウントで動く他のプログラムからファイルを隠す仕組みではありません。

## バックアップと戻し方

- バックアップは、今の利用者の資料・調査・表示の設定を JSON で書き出します。パスワードとセッションは含みません。
- 復元は「足す」方式で、同じ資料は重ねません。別の環境の資料 ID は付け直します。
- 全体を前の版に戻す時は、画面を止めてから `local-data/` を写しておき、コードとその時のデータベースの写しを組で戻します。データベースの形が分からない版へ上書きしないでください。

## 資料を消す・差し替える・受け箱(2026-11-02)

- 社内資料の画面で、行のごみ箱 → 「削除する」で 1 件消えます(「やめる」で戻る)。消した資料はバックアップからだけ戻ります。
- AI や道具から本文を差し替える時は `POST /api/documents/<id>/replace`(本文 `body`・題名 `title` は任意)。同じ id のまま、古い本文は検索にも残りません。消す時は `POST /api/documents/<id>/delete`。どちらも自分の資料だけです。
- `local-data/inbox/` に置いた `.md` / `.txt` は 30 秒ごとに資料に入り、`inbox/done/` へ移ります。
- バックアップの復元は 8MB ずつ分けて送り、PC の中で 1 件ずつ戻します(資料 300MB の上限いっぱいでも戻ります)。
